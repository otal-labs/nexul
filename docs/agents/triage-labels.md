# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those
roles to the actual strings used in this repo's tracker. They're recorded as a
`**Status:**` line near the top of each issue file in `.scratch/`.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Needs evaluation before anyone starts it |
| `needs-info`               | `needs-info`         | Waiting on more information              |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human hands (dashboards, secrets, judgement calls) |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the
corresponding string from this table.

Edit the right-hand column to change the vocabulary.
