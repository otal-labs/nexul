# Architecture Decision Records

Architectural decisions go here as `NNNN-slug.md`. Scan the directory for the
highest number and increment by one. An ADR can be a single paragraph — the
value is recording *that* a decision was made and *why*, not filling in
sections.

Record one only when all three are true: the decision is **hard to reverse**,
**surprising without context**, and **the result of a real trade-off**. If it's
easy to reverse, skip it — you'll just reverse it. Explicit no-s and rejected
alternatives count, when the rejection is non-obvious.

ADRs 0001–0010 were written before the project's older decisions were migrated
into 0011 and up, so the numbering is sequential but not chronological.
