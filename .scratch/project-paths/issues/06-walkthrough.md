# 06: Walk both scenarios end to end

Type: task
Status: open
Blocked by: 04, 05

## Question

On a fresh local stack, walk both scenarios in the browser: a project for a
client with no repository (docs written, client invited), and a project with
a repository attached and not deployed, later deployed through the prompt.
Check every surface: the interview offer, the board, project settings, the
reverse path (detaching the repository brings the "no repository" state
back). Fix the website guides the change makes wrong, update
`CONTEXT.md` if a term moved, and move the roadmap entry to shipped.
