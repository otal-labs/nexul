# 05: The note pill and its file dialog

Type: prototype
Status: open
Blocked by: 01, 04

## Question

In the thread, a note is one line from the Agent plus a file pill. Clicking
the pill opens a dialog that renders the file the way the ticket body
renders, and lets a person edit and save it. What do the pill and the
dialog look like?

- The pill inside an Agent message in the new thread column, next to the
  existing attachment pills.
- The dialog: reading view, the switch into editing, save and cancel, and
  how versions show if editing keeps them.
- The same file's pill under the ticket's attachments, and whether clicking
  it there opens the same dialog.

Prototype the candidates live; the owner picks by looking.
